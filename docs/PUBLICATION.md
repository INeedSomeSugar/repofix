# 公开仓库范围

本仓库发布独立实现、五个原始合成任务、三个固定MIT许可上游函数裁剪任务、三个首次模型运行前冻结的合成任务、工程测试、演示截图和已保存的开发试验证据。新合成任务现已完成首次模型评估，后续仅作回归。`work/`、虚拟环境、缓存和真实凭据不提交。

`reports/evidence/` 来自合成代码任务，不包含相邻CraneAssist的事故资料。报告保留原始运行结果、失败、用量与证据摘要；不能把开发任务通过率写成外部基准表现。

本机Docker启动修复记录位于工作区上级的`environment-setup/`，不属于独立仓库。新机器安装Docker后，先运行README中的`runner-check`；不得假定本机的镜像或验证记录代表其他机器。
